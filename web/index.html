A CONTROLLED SYSTEM

Automation should show its work.

Lotwise preserves extracted source text and file hashes. Numerical checks use explicit rules. Unmapped units and uncertain identity remain review items. A human reviewer owns the final disposition. Lotwise does not certify food safety, replace laboratory testing, or release batches.
